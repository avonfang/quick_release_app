## 一、产品概述

### 1.1 产品简介

「看见此刻」是一款 **AI 引导式情绪觉察工具**。它不替用户解决问题，而是通过 AI 对话、引导式练习和觉察卡片，帮助用户看见情绪背后的自动想法与核心信念，让信念在被看见的瞬间自然松动，从而逐步建立更健康的情绪觉察能力。

### 1.2 产品定位

| 项目 | 说明 |
|------|------|
| 产品名称 | 看见此刻（英文标识：Mindful Awareness） |
| 一句话定位 | AI 引导式情绪觉察工具 |
| 目标用户 | 有情绪困扰、希望自我成长、练习觉察与冥想的普通用户 |
| 核心价值 | 从"被情绪控制"到"看见情绪"，从"认同信念"到"松动信念" |
| 使用时长 | 快速觉察约 1-3 分钟；深度对话 5-15 分钟；练习 1-10 分钟 |

### 1.3 产品理念

- **看见即松动**：困扰往往来自无意识认同的信念，被看见的信念会自然松动。
- **不评判、不指导**：AI 扮演觉察引导者，只提问、不分析、不说教。
- **本地优先**：数据默认保存在用户设备，登录后可选择云端同步。
- **低门槛**：支持快捷选项、语音输入、短回复兜底，让用户容易开口。

### 2.2 首页

首页是产品的总入口，包含：

- **问候与每日一言**：按时段展示问候语和当日金句。
- **每日签到**：签到获得金币，累计连续签到天数，触发里程碑奖励。
- **练习数据概览**：连续练习天数、本周专注分钟数。
- **情绪选择区**：快速进入对应练习——
  - 焦虑 → 4-7-8 呼吸
  - 愤怒 → 箱式呼吸
  - 低落 → 身体扫描
  - 纠结 → 观察思维
  - 不确定 → 先安顿一下
- **快速觉察入口**：一键进入四步 AI 觉察记录流程。
- **练习卡片**：今日推荐练习入口。

### 2.3 快速觉察（核心轻量功能）

**入口**：首页「⚡ 快速觉察」卡片

**流程（四步）**：

1. **选择情绪**：开心 / 平静 / 焦虑 / 烦躁 / 疲惫 / 难过，并标注强度（1-10）。
2. **描述事件**：今天发生了什么。
3. **记录自动想法**：我注意到我在想……
4. **判断事实或担心**：这个想法更像事实，还是一种担心。

**AI 回应**：提交后 AI 返回三段式回应——共情回应、自动想法识别（"也许你心里有这样一个声音……"）、一个温和的探索问题。

**特性**：

- 中途退出自动保存草稿，下次进入可恢复。
- 每天有"今日已记录"标记，并生成最近 14 天的情绪模式摘要（情绪分布、反复出现的想法）。
- AI 不可用时自动降级为本地兜底回复，流程不中断。
- 登录后记录自动同步到云端。

### 2.4 AI 深度对话（核心功能）

**入口**：快速觉察页 / 卡片页 / 记录页

**八阶段引导路径**：

| 阶段 | 内容 | 深度 |
|------|------|------|
| 1 事件 | 了解触发情绪的具体事件 | 快速通过（1-2 轮） |
| 2 情绪 | 识别当下的真实感受 | 快速通过（1-2 轮） |
| 3 自动想法 | 捕捉脑海里的那句话 | 快速通过（1-2 轮） |
| 4 信念 | 转化为"如果 X，就说明 Y"的信念结构 | 核心深度阶段 |
| 5 松动 | 看见信念只是想法，不是事实 | 核心深度阶段 |
| 6 释放 | 释放法：感受 → 允许 → 放下 | 核心深度阶段 |
| 7 觉察 | 新视角下重新理解事件 | 深度阶段 |
| 8 行动 | 找到最小的下一步行动 | 收尾阶段 |

**关键机制**：

- AI 回复中携带系统标记（【过渡】【信念】）自动推进阶段，标记对用户不可见。
- 前三个阶段最多各 2 轮对话，防止过度挖掘，深度留给信念与释放阶段。
- 信念提取强制使用"如果……就说明……"句式，并经用户确认后写入记录。
- AI 逐字流式输出，增强陪伴感。
- 对话过程自动保存草稿，退出后可恢复；AI 故障时使用本地兜底话术，2 轮后照常推进。
- 对话完成自动生成觉察卡片并跳转。

### 2.5 觉察卡片

一次完整的觉察对话自动生成一张结构化的觉察卡片，包含 8 个区块：

📌 触发事件 → 💧 情绪感受 → 💬 自动想法 → 💭 核心信念 → 🫳 松动信念 → 🕊 释放练习 → 👁 新的看见 → 🎯 下一步行动

**特性**：

- 可查看完整对话回顾。
- 一键**生成图片分享**（微信端 Canvas 绘制、H5 端 html2canvas），便于社交传播。
- 可继续对话、保存记录（本地 + 云端同步）。

### 2.6 情绪急救

**入口**：首页情绪选择区 / 练习页

**四步流程**：

1. **停下来**：给自己一点空间，时长 1 分钟。
2. **识别情绪**：选择焦虑 / 愤怒 / 低落 / 纠结，每种情绪有专属引导路径。
3. **引导觉察**：每种情绪 8 个步骤，包含呼吸、身体定位、观察想法、观察者视角、扩展空间、回归呼吸等。
4. **记录与评分**：写下此刻感受，为"现在感觉好些了吗"打分（1-5 星）。

**特性**：

- 完成后 +1 ❤️ 金币，并推荐相关课程。
- 提供深入对话（AI）入口。
- 页面内置心理援助热线提示（400-161-9995）。

### 2.7 呼吸练习

**入口**：首页情绪选择区 / 练习页

- 多种呼吸模式（如 4-7-8 呼吸、箱式呼吸、身体扫描等）。
- 每轮呼吸含阶段提示与倒计时，支持多轮次练习。
- 完成练习 +1 ❤️ 金币。
- **高级呼吸模式**需订阅"此刻·陪伴"解锁。

### 2.8 此刻信箱

**入口**：首页 / 我的页

- 给"此刻"写信，自由表达情绪和想法。
- 基于关键词情绪识别引擎（焦虑 / 愤怒 / 低落 / 纠结 / 感恩），自动生成有温度的回应，并推荐对应练习。
- **免费额度**：每天 5 封；订阅后无限使用。
- 内置"不知从何说起"快捷引导，降低表达门槛。
- 包含签到、连续天数、里程碑奖励（金币）。

### 2.9 课程体系（探索）

三条觉醒之路，共 18 节课，每课含"概念 + 练习"：

| 路径 | 来源 | 主题 |
|------|------|------|
| 🌿 临在之路 | 《当下的力量》（Eckhart Tolle） | 从思维认同中解放 |
| 🍂 臣服之路 | 《臣服实验》（Michael Singer） | 对当下说是 |
| 💫 开放之路 | 《清醒地活》（Michael Singer） | 释放内心能量阻塞 |

- 完成课程标记进度、+2 ❤️ 金币。
- 三条路径全部完成可解锁对应成就。

### 2.10 记录 / 洞察 / 信念

**记录**：

- 查看全部觉察记录，含状态（进行中 / 已完成）、事件、信念摘要。
- 支持删除（本地 + 云端同步删除）。
- 登录后自动合并本地与云端记录（按更新时间去重）。

**洞察**：

- 积累 ≥3 条记录后可生成 AI 心理洞察。
- 输出内容：思维类型（过度责任型、评价敏感型、未来担忧型、关系共情型、完美倾向型、自我批评型、控制需求型、回避冲突型）、一句"被看穿"式的核心发现、模式分析、有温度的总结。
- AI 不可用时本地规则兜底分析。

**信念**：

- 统计所有记录中出现的核心信念，按频率分为高频、常见、偶尔出现。
- 展示"核心信念数量 / 累计出现次数 / 涉及记录数"。

### 2.11 账号与登录

- **邮箱注册 / 登录**：密码加密存储（bcrypt），JWT 登录态有效期 7 天。
- **微信一键登录**：小程序 code2session 换取 openid，自动创建账号。
- **忘记密码**：邮箱发送重置链接（有效期 1 小时）。
- **修改密码**：登录状态下验证原密码后修改。
- 登录后启用云端同步（记录、卡片），未登录时全部数据保存在本地。

## 五、数据与安全

### 5.1 数据策略

- **本地优先**：金币、课程进度、信箱历史、签到、快速记录默认保存在设备本地。
- **云端同步**：登录后，觉察卡片 / 记录自动同步到服务器，多端合并去重。
- **存储隔离**：新旧功能使用独立存储键（如 `awakeningCoins`、`quickRecords`、`cards`），互不冲突。

### 5.2 安全措施

- API 密钥（DeepSeek、百度 ASR、微信）全部保存在服务端，不暴露给客户端。
- 密码使用 bcrypt 加密存储。
- 登录、注册、找回密码接口均有限流保护。
- 通过 JWT 鉴权访问用户数据和云同步接口。

## 六、技术架构

### 6.1 前端

- uni-app（Vue 3 + TypeScript + Vite + Pinia）
- 一套代码编译发布微信小程序与 H5
- 自定义底部导航，深色暖调全局主题（背景 #2A231D）

### 6.2 AI 能力

| 能力 | 服务 | 说明 |
|------|------|------|
| 深度觉察对话 | DeepSeek | 八阶段引导，系统提示词控制节奏 |
| 快速觉察回应 | DeepSeek | 三段式回应，本地兜底 |
| 心理洞察分析 | DeepSeek | 8 类思维类型识别 |
| 语音识别 | 百度 ASR（微信端）/ Web Speech API（H5） | 录音转文字 |

### 6.3 后端

- Node.js + Express
- SQLite（better-sqlite3）数据库
- 模块：认证（auth）、AI 对话代理（chat）、记录同步（records）、语音识别（asr）

### 6.4 部署

- 后端：VPS 服务器（端口 3001）
- 边缘代理：Cloudflare Pages Functions（/api → VPS，/v1 → DeepSeek）
- 备选部署：Vercel、Cloudflare Worker
- 小程序：微信开发者工具导入构建产物

## 九、附录：开发与运行

```bash
npm install              # 安装依赖
npm run dev:mp-weixin    # 微信小程序开发模式
npm run build:mp-weixin  # 生产构建 → dist/build/mp-weixin/
npm test                 # 运行 Jest 测试
```

小程序 AppID 配置在 `src/manifest.json` 的 `mp-weixin` 段。
